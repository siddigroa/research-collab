=============================================================================
HOW TO UPLOAD TO GITHUB
=============================================================================

Option A: Web Interface (Easiest)

1. Go to your GitHub repository
2. Click "Add file" → "Upload files"
3. Select files to upload
4. Make sure path is correct (templates/ for HTML files)
5. Click "Commit changes"

Option B: GitHub Desktop (Recommended)

1. Download GitHub Desktop from github.com/desktop
2. Clone your repository
3. Copy files to the folder
4. Click "Commit" in GitHub Desktop
5. Click "Push"

=============================================================================
AFTER UPLOADING - DEPLOY TO RENDER
=============================================================================

1. Go to: https://render.com
2. Sign up (or use GitHub login)
3. Click "New Web Service"
4. Select your "research-collab" repository
5. Configure:
   - Name: research-collab
   - Build command: pip install -r requirements.txt
   - Start command: gunicorn app:app
6. Click "Create Web Service"
7. Wait 2-3 minutes for deployment

Your app will be live at a URL like:
https://research-collab-xxxx.onrender.com
